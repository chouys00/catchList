# 🎬 IMDb 新上映電影 ➔ 豆瓣估算評分轉換器

自動抓取 IMDb 近期新上映電影，套用豆瓣偏好修正公式（基於 100 部電影大數據回歸），篩選並整理成 `電影.md` 報告。

---

## 📂 目錄結構

```
imdb_tracker/
├── main.js          ← 主程式（執行這個）
├── config.js        ← 設定（API Key、門檻、修正係數）
├── fetcher.js       ← IMDb 資料抓取（OMDb API / 公開數據集）
├── converter.js     ← IMDb ➔ 豆瓣評分轉換
├── writer.js        ← 輸出 電影.md
├── package.json     ← npm 依賴
└── 電影.md          ← 自動生成的報告（執行後出現）
```

---

## ⚡ 快速開始

### 1. 安裝依賴
```bash
npm install
```

### 2. （可選）設定 OMDb API Key
開啟 `config.js`，填入您的 Key（[免費申請](https://www.omdbapi.com/apikey.aspx)，每日 1000 次）：
```js
OMDB_API_KEY: "你的Key",
```
> 不填也能用！工具會自動切換到「IMDb 公開數據集模式」（每日更新，完全免費）。

### 3. 執行
```bash
# 抓取最近 3 個月（預設）
node main.js

# 抓取最近 6 個月
node main.js --months 6

# 只抓取特定月份
node main.js --year 2026 --month 6
```

## 📐 轉換公式

| 類型 | 修正 | 說明 |
|:---|:---:|:---|
| 一般外國真人片 | **-0.15** | 基準值 |
| 動畫片 | **+0.30** | 豆瓣偏好動畫 |
| 文藝/劇情/得獎片 | **+0.10** | 豆瓣文藝社群加成 |
| 紀錄片 | **+0.10** | 同上 |
| 喜劇 | **-0.10** | 幽默感有文化差異 |
| 驚悚/恐怖 | **-0.20** | 豆瓣對恐怖片較嚴苛 |
| 特效商業大片 | **-0.50** | 豆瓣最嚴苛 |
| 華語本土電影 | **+0.70** | 主場情感加成 |

> 統計來源：100 部近 5 年熱門電影，IMDb vs 豆瓣線性回歸，$r = 0.773$
