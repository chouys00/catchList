# 真人劇年度研究清單

2015～2026 年皆有年度 JSON，每年韓劇、日劇、台劇、陸劇、歐美劇各 10 筆，共 600 筆。此數字包含不同年份入選的同系列續季，不代表 600 個不同系列。

2022 年沿用既有檔案。本次於 2026-09-23 新增其餘 11 年、550 筆作品，已補入 `G:/我的雲端硬碟/CatchList/真人劇年度.md`。

## 選片與年份

- AI 參考公開在地口碑、創作代表性及年度話題，整理可優先觀看的作品；不是各網站榜單的機械合併，也不是客觀名次。
- 新增資料以作品或該季在原產地首次播出的年份歸檔。跨年完結不移至隔年；海外重播或臺灣上架也不改年份。
- 續季標示季數，影集與同名電影需要區分時加註。沒有確認臺灣通用譯名的作品保留原名。
- 年度回顧可能收錄前一年開播的劇，不能直接把該榜單年份當首播年。例如《大江大河2》列在 2020，《繁花》列在 2023，《植劇場－天黑請閉眼》列在 2016。
- 不以 TMDb、IMDb、Wikidata 或臺灣串流上架資訊決定入選。既有 2022 年內容保留，未套用本次重新編輯。

## 來源與資料限制

每份新增 JSON 的 `researchSources` 按地區保存研究參考網址，`editorialNotes` 說明當年的整理取捨。來源包含年度劇評、公開榜單、獎項名單及播出目錄；播出目錄只用於核對名稱與年份，不單獨代表品質背書。來源按地區彙整，並非每筆作品都被每篇文章推薦。

`status`、`researchAsOf`、`yearBasis`、`selectionMethod`、`editorialNotes`、`researchSources` 與 `imdbDataNote` 是研究紀錄；現行更新器不驗證或輸出這些額外欄位。年份與作品事實仍須由整理者核對。

本次 550 筆新資料的 IMDb 分數與票數均留空，報告顯示「IMDb：資料不足」，不使用其他網站分數代替。既有 2022 年的 IMDb 資料原樣保留。清單不保證作品目前在臺灣可訂閱觀看。

## 2026 年暫選

2026 年尚未結束，這份名單只涵蓋截至 2026-09-23 已播出的入選作品，並非全年定稿，也不代表所有作品都已完結。JSON 標示 `status: provisional`，報告的年度整理時間也明示「截至當日暫選，非全年定稿」。

同年已存在時，更新器會直接跳過。年底即使修改 `2026.json`，重跑也不會自動更新報告；屆時須重新研究、預覽差異，並取得既有年度內容修改的授權後再處理，不可直接刪除年度區段來繞過保護。

## 使用與驗證

從專案根目錄預覽單一年度：

```powershell
npm run update:tv -- --year 2015 --input annual-selections/2015.json --dry-run
```

補齊紀錄見 [2015～2026 驗收紀錄](../../docs/live-action-tracker/BACKFILL_2015_2026.md)。更新器的格式驗證不等於事實查核；正式寫入前仍須核對首播年、季數及引用內容。
