## 補齊方式

執行 `node scripts/backfill-anime-sources.mjs --data-dir=資料夾` 只寫入 output/anime-source-repair/preview。加 --apply 才寫入報告旁的 .catchlist-anime-sources.json。遇到不同的既存紀錄會停止，原檔保留；相同內容可重跑。執行前確認所有對照仍存在於報告，執行後確認報告位元組不變。

## 後續抓取

抓取器從 Jikan 季度資料、AniList 備援詳細資料一路保留 MAL 編號、原文名稱、圖片、影片、集數與類型。先以原子寫入保存來源檔，成功後才更新 Markdown 季度；來源保存失敗不推進季度。若寫報告失敗，只留下尚未被報告引用的來源，下次可重試。

中文翻譯只接受唯一精確原名比對，舊版按搜尋排名選取的翻譯快取失效；無法確認時保留原文。報告格式不變。來源檔以名稱及季度定位，不含評分，評分變動不會失去對照。

閱讀器先採用已核對來源，舊未配對快取不會阻擋。手動校正優先；沒有來源檔時維持舊版行為。圖片與影片網址均經原本的來源限制檢查。來源檔可隨資料夾同步，但沒有多台同時寫入的衝突合併功能。
