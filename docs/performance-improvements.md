## 實作與驗證

- 電影先套用原票數、國別與評分規則，再建立候選專用地區索引；空候選不下載地區資料。原寫入門檻仍保留。
- 閱讀器只在讀取畫面時使用報告解析快取。新增、刪除與交易復原維持即時讀檔；個人狀態不快取。
- Steam 詳細資料的 1.5 秒等待移入真正網路請求之前。原有版本不符的快取仍會重抓。
- 搜尋快取只依不可變的畫面資料快照及實際篩選條件重用；標籤面板展開、捲動不重算。
- 資料快取以逐筆 JSON 日誌保存，每 100 筆及更新結束合併；合併先原子替換完整檔，再移除日誌，中斷可重播。這是單一更新程序使用的快取，未新增多程序共同寫入能力。
- 封面每批四個網址合併存檔；意外終止僅可能重抓未存的一批，不影響清單與個人紀錄。
- 初始化進度沿用 version 1 完整格式，以記憶體與日誌處理逐款進度，正常結束合併；離線來源與篩選不變。
- 動畫三個來源都設定 15 秒逾時、保留原重試上限。成功中文名快取 30 天；失敗或空結果不快取，分數仍由來源即時取得。
- 排程預設最多兩個追蹤器同時執行；狀態由父程序同步寫入，失敗彙整與非零結束碼保留。

## 可重跑量測

命令：`node scripts/performance-check.mjs`。只讀正式遊戲報告；寫入皆在自建暫存資料夾。

本機 3,111 筆資料測量：報告讀取與解析中位數由 98.321 ms 降為快取命中 0.325 ms；相同搜尋排序由 14.979 ms 降為重用結果 0.001 ms。兩次不同搜尋合計 2.476 ms。此數據不含畫面繪製，首次載入仍須完整解析。

250 筆新增資料的完整快取寫入由 250 次降為 3 次，另有逐筆的小型恢復日誌。三項各 100 ms 的模擬排程由 333.1 ms 降為 217.2 ms；不代表真實網路一定有同比例改善。
