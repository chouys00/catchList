# 閱讀器三項優化規格
## 背景與目標
依「盤點專案效能與使用體驗」對話的實際重現結果，完成三項局部改善，同時驗收已安裝新版四個 SKILL 的真實接力。
## 功能與品質需求
- REQ-001：動畫搜尋、清除搜尋等局部更新後，新作品列會啟動封面與影片查詢；不能一直顯示等待卻不發請求。保留快取、延遲載入、錯誤處理與避免重複請求。
- REQ-002：遊戲、動畫、電影、真人劇各自記住本次閱讀器工作階段的捲動位置；首次進入從頂端開始，切回恢復合理位置。遊戲需配合分批列表，先有足夠內容再恢復，避免捲動被截短。保留各頁篩選，不新增永久個人資料寫入。快速切換與非同步載入不得套用過時頁面的位置。
- REQ-003：展開或收合單款遊戲標籤只更新必要作品列，不重建整個已顯示清單。保持其他列 DOM、已載入數量、封面、捲動位置、點擊行為與鍵盤操作。500 列情境以實際節點保留與操作結果驗證，時間只作量測，不設定機器無關的毫秒門檻。
- REQ-004：每階段遵守根 AGENTS.md 的 patch 版本、可攜版重建及雲端副本規則。保持 Electron portable 正式入口，不擴充 Tauri 功能。
- REQ-005：C1、C2、C3 各在不同新對話完成；先 claimed 再寫實作，派出前模式／ID／目標一致；後續自動接續，C3 完成停止。記錄真實測試、建置、版本、EXE 路徑及雜湊，不能僅留摘要。
## 非目標與相容性
不重做 UI、不新增追蹤來源，不執行連網更新，不修改報告或個人紀錄。既有快取、搜尋、收藏、隱藏、影片及分批載入需保持可用。
## 資料與既有修改
保留啟動前 6 個未提交檔案，基準與原內容備份在 output/reader-ux-optimizations-20261005/。library.js、tauri-shell/library.js、legacy-game-tags.js 與其測試是使用者既有工作，不為本輪重寫；package.json 與 lock 僅依版本更新必要欄位，保留其他差異。沒有 commit、push 或其他專案修改的本次授權。
## 使用者與成功條件
閱讀器使用者可正常搜尋動畫、跨頁續讀及展開長清單標籤。三項有實際 Electron renderer 互動回歸證據，相關測試通過，各階段正式可攜版建置與同步成功，整段狀態 completed。
## 已知未知
原檢查閱讀器 122 項測試通過；本輪既有未提交功能可能增加項數，需以實際結果記錄。Windows 沙箱可能阻擋 Electron，先在已授權範圍內提升執行權限處理，不因此擴大寫入正式資料。
