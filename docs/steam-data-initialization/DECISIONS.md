# 決策紀錄

## DEC-001：以目前 Steam 分支作為基底

- 日期：2026-09-08
- 狀態：accepted
- 決定：從 `codex/adjust-game-selection` 的現況切出 `codex/steam-initialize-data`，不從 `master` 重新開始。
- 原因：目前分支已有全語系搜尋設定、繁簡中文欄位、社群標籤快取、可指定預覽輸出、取樣模式與較完整的限流處理，可供初始化流程重用。使用 Node 22 執行時，目前分支有 26 項 Steam 測試通過；`master` 有 16 項通過。
- 影響：初始化流程可保持獨立入口，同時使用已測試的 HTTP、標籤與輸出能力。既有未提交變更必須保留，不得清除或覆寫。

## DEC-002：初始化與每月更新永久分流

- 日期：2026-09-08
- 狀態：accepted
- 決定：新增獨立 `initialize` 入口；既有 `update`、`update:games` 與 `update:all` 不會自動執行初始化。
- 原因：兩者的資料量、來源、失敗恢復與執行頻率不同。
- 影響：日後每月排程仍使用搜尋頁、`appdetails` 與商店頁；是否減少每月 API 數量留待另一項工作處理。

## DEC-003：初始化正式資料只用兩個來源

- 日期：2026-09-08
- 狀態：accepted
- 決定：先讀 FronkonGames，再對第一輪候選各讀一次 Steam 商店頁面。初始化執行期禁止使用搜尋頁與 `appdetails`。
- 原因：先用大量資料集減少候選，再把必要補查集中在同一份頁面，可避免每款遊戲再打多支端點。
- 影響：A1 必須證明單頁資料足夠；證明失敗時不可偷偷加入替代 API。

## DEC-004：全語系終身評價是阻擋條件

- 日期：2026-09-08
- 狀態：accepted
- 決定：最終篩選必須使用全球全部語言、終身累積的好評率與評論數。
- 原因：這是使用者最重視的篩選欄位。最近 30 天或目前介面語言的終身評論都不符合需求。
- 影響：若單一商店頁面無法穩定提供這組資料，A1 結果為 `CONCERNS`，等使用者決定是否放寬來源。

## DEC-005：分類以最新社群標籤為主

- 日期：2026-09-08
- 狀態：accepted
- 決定：第二輪分類先用商店頁面的社群標籤，再用頁面功能分類與 FronkonGames 欄位補充。
- 原因：現行專案已對所有入選遊戲補抓社群標籤，且使用者指定分類以此為主。
- 影響：規則優先比對穩定 ID；文字翻譯、別名與缺標籤都要保存來源，避免誤判。

## DEC-006：硬性欄位採未知狀態

- 日期：2026-09-08
- 狀態：accepted
- 決定：免費、內購、MMO、VR、搶先體驗與評價解析不到時記為 `unknown`，不預設為安全。
- 原因：HTTP 200 仍可能是年齡驗證或不完整頁面；缺少購買區塊也可能代表下架或地區限制。
- 影響：未知資料進入待重試／待確認清單，不列入最終通過清單。

## DEC-007：VR 與 PvP 的排除口徑

- 日期：2026-09-08
- 狀態：accepted
- 決定：VR 只排除「僅限 VR」，保留可選 VR 模式；任何明確 PvP 標籤依本次需求排除。
- 原因：VR 沿用前面已確認的「僅限 VR」條件；目前目標明確把 PvP 放入第一輪排除項目。
- 影響：附帶 PvP 的遊戲也可能被排除，規則必須在排除明細顯示命中的標籤與來源。

## DEC-008：完整資料只寫初始化專用預覽

- 日期：2026-09-08
- 狀態：accepted
- 決定：輸出固定在 `steam_discovery/preview/initialization/`，不覆蓋現有預覽或雲端 `遊戲.md`。
- 原因：初始化結果需要先稽核，正式資料搬移又屬於難以復原的操作。
- 影響：搬移或合併須另行取得使用者明確授權。

## DEC-009：FronkonGames 初篩與選擇性 Reviews API 複核（已取代）

- 日期：2026-09-08
- 狀態：superseded
- 背景：A1 證實繁中商店頁沒有全球全語系終身評價，但使用者補充其已於 2026-09-07 抽查多款遊戲，FronkonGames 的 `positive`／`negative` 與同日 SteamSpy 完全一致。
- 考慮方案：停止使用 FronkonGames、把商店頁中文評價當替代值，或以資料集初篩並只複核風險資料。
- 決定：FronkonGames 保留為大量初篩與全球全語系終身評價的依據。官方 Steam Reviews API 可在 0／0、異常、接近可設定門檻及最終入選候選時複核。
- 理由：資料集對正常、遠離門檻的遊戲有實際初篩價值；少量 API 複核把可能不同步的風險集中在會改變結果的資料。
- 影響：取代 DEC-003 的「只用兩個來源」限制與 DEC-004 對單一商店頁的阻擋判定。仍禁止搜尋頁與 `appdetails`，不得以最近或目前語言評價替代全語系終身資料。
## DEC-010：FronkonGames 為現行依據，Reviews API 維持未決

- 日期：2026-09-08
- 狀態：accepted
- 背景：使用者明確指出 FronkonGames 可以繼續支撐 A1 與後續階段；是否另用 Steam Reviews API 尚未決定。
- 決定：固定 FronkonGames `positive`／`negative` 作為本計畫的全球全語系終身評價與評論數來源。Steam Reviews API 只保留 A1 對照證據，不列入正式初始化資料來源。
- 影響：取代 DEC-009 的 API 授權推論。`0/0`、異常與門檻附近資料列為待確認，不影響正常且遠離門檻資料的初篩與後續處理。
## DEC-011：A2 的門檻附近資料保留規則

- 日期：2026-09-08
- 狀態：accepted
- 決定：第一輪把好評率 84.5% 至未滿 85%，以及正好 500 則評論的資料列入待確認；85% 且評論數大於 500 的資料可成為候選。
- 原因：避免固定資料集輕微不同步時，把最接近門檻的未達值混入一般不合格，同時保留規格明訂的未四捨五入 85% 與大於 500 則判定。
- 影響：待確認清單是可追查的安全暫置，後續不會把它當成通過資料。

## DEC-012：0／0 評論資料一律捨棄

- 日期：2026-09-10
- 狀態：accepted
- 決定：FronkonGames 中 `positive = 0` 且 `negative = 0` 的 42,899 筆資料，從 A6 第一輪候選直接排除。
- 原因：使用者已作出最終決定，避免把不完整來源資料與外部複核結果混合。
- 影響：不得整合獨立驗證的任何值，包括 125 筆 SteamSpy 有效評論、32,505 筆有效零值及所有布林 `false` 預設。V1～V4 僅作稽核證據；`zero-review-validation/validation-results.jsonl` SHA-256 為 `543525324f721c271ef79bc940a8940778f2729364c64c83abd1564b8bc3b87f`。

## DEC-013：使用非個人化成人確認 Cookie

- 日期：2026-09-10
- 狀態：accepted
- 決定：本機初始化的 Steam 商店頁請求使用固定成人日期 Cookie，不使用帳號、登入狀態、真實生日或其他使用者個資。
- 驗證：AppID 1196590 與待重試清單前 5 款均取得完整商店頁，不再回傳 `age_gate`。
- 影響：只處理同一個 `store.steampowered.com/app/{appid}` 來源，不改變輸出範圍或遠端寫入限制。

## DEC-014：接近門檻資料直接捨棄

- 日期：2026-09-10
- 狀態：accepted
- 決定：所有 509 筆接近門檻資料直接排除，不再保留待確認名單。
- 範圍：好評率 84.5% 至未滿 85% 的 500 筆，以及評論數正好 500 則的 9 筆；其中 6 筆同時屬於好評率範圍，最終以好評率原因記錄。
- 影響：`評論缺失.json` 為空；初始化清單只保留符合既定門檻且已完成第二輪判定的遊戲。

## DEC-015：繁簡中文合併為單一支援狀態

- 日期：2026-09-10
- 狀態：accepted
- 決定：初始化與既有每月更新流程一律將繁體中文、簡體中文視為中文；任一語系受支援就判定為「支援中文」。
- 影響：報告與流程結果只記錄單一中文支援狀態，不再分開顯示或保存繁體、簡體中文欄位。頁面解析器仍可在解析當下辨識兩種語系，但只用來計算合併結果。
