# 決策紀錄

## D-001：刪除成功後套用局部結果

- 日期：2026-09-02
- 狀態：accepted
- 背景：現行刪除後會重新讀取全部清單與遊戲標籤，Google 雲端硬碟冷載入實測約 2.3 秒。
- 考慮方案：完整 snapshot、只重新載入受影響清單、回傳並套用局部變更。
- 決定：後端回傳局部結果，renderer 只更新受影響清單。
- 理由：刪除時後端已解析目前報告，可重用既有資料，避免重讀其他清單與 667 KB 遊戲標籤 sidecar。
- 影響：IPC 回傳格式與 renderer 狀態更新需同步修改；初次載入與選擇資料夾仍使用完整 snapshot。
- 取代關係：無。

## D-002：第一版等待後端成功才更新畫面

- 日期：2026-09-02
- 狀態：accepted
- 背景：先移除畫面資料可讓反應看似立即，但寫檔失敗時需處理回復及狀態分歧。
- 考慮方案：樂觀更新、後端成功後局部更新。
- 決定：第一版在後端確認備份及寫檔成功後才套用局部結果。
- 理由：已確認主要延遲來自完整 snapshot；先移除該瓶頸即可大幅改善，並維持資料安全。
- 影響：若 Google 雲端硬碟單次寫檔仍長時間阻塞，後續才另案評估樂觀更新。
- 取代關係：無。
