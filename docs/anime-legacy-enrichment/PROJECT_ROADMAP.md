# 執行計畫
計畫版本 1。順序 A1 → A2 → A3 → 使用者確認具體預覽 → A4。整體完成條件見規格；新裝置先只執行 A1～A3。各階段循序，無並行候選。

## A1：新裝置盤點與安全預覽入口
### 需求對應
REQ-001、REQ-006、REQ-009、REQ-010。
### 目標
確認實際程式與資料，建立只寫隔離輸出的盤點入口。
### 非目標
不查外部來源、不更動正式資料或閱讀器。
### 前置條件與相依階段
無；取得實際 repo、資料路徑及基準提交或相容後繼版本。
### 預期成果
output/anime-legacy-enrichment/<run-id>/manifest.json、inventory.json；保存實際路徑、HEAD、工作目錄狀態、輸入雜湊。
### 實作方向
復用 sourceEntries、readAnimeSources 計算差集；缺檔不靜默生成。雜湊不同先釐清原因，合法新收錄可記錄差異並建立新基準，不強求 131 筆；無法解釋先暫停依賴工作。
### 可能影響的系統或資料
scripts 及隔離 output，正式資料只讀。
### 階段內任務與並行候選
A1-T1 環境核對（無相依）；A1-T2 盤點入口（依賴 T1）；A1-T3 安全驗證（依賴 T2）。均 parallel_candidate: false，循序執行。
### 必要測試
差集、同名多季、重複列保留；缺檔及來源格式錯誤保護；正式檔雜湊不變。
### 完成條件
盤點可重現，範圍、讀寫位置與保護確認。
### 人工或外部驗收
類型：none；缺資料且無法自行發現位置才詢問。
### 風險與未知事項
隱藏來源檔可能未同步，原裝置快取不在 Git。

## A2：收集候選及可補資訊
### 需求對應
REQ-002、REQ-004、REQ-005、REQ-007、REQ-009。
### 目標
按需查詢全體目標，保存 AI 判斷證據與欄位。
### 非目標
不正式套用，不大量下載圖片，不把查詢排名當身分。
### 前置條件與相依階段
A1 PASS。
### 預期成果
同一 run 下 candidates.json、evidence/、requests.jsonl、checkpoint.json；來源 URL、時間、原始回應與失敗原因可追溯。
### 實作方向
先快取再查詢，以名稱、別名、季別、日期與版本辨認候選。有歧義時補查；先小批確認品質和請求量，再持續完成其餘目標。詳細資訊順便保存，成功結果續跑不重抓。
### 可能影響的系統或資料
公開來源請求與本機預覽；不得上傳個人紀錄。
### 階段內任務與並行候選
A2-T1 查詢快取管線（依賴 A1）；A2-T2 小批驗證（依賴 T1）；A2-T3 全量候選收集（依賴 T2）。均 parallel_candidate: false，循序執行。
### 必要測試
限流退避、有限重試、續跑與快取重用、請求統計可由日誌重算，錯誤不混同缺欄位。
### 完成條件
每個目標有候選證據或明確查詢缺口；進度及請求總量已保存。
### 人工或外部驗收
類型：non-blocking；來源不可用列缺口並繼續。
### 風險與未知事項
錯譯、限流、來源分類差異、影片連結失效。

## A3：AI 信心評估與審閱預覽
### 需求對應
REQ-003、REQ-005、REQ-006、REQ-008、REQ-010。
### 目標
逐列閱讀證據，提供可決定套用範圍的預覽。
### 非目標
不因高信心寫正式來源，不自動更名或更新評分。
### 前置條件與相依階段
A2 PASS；可保留已明示查詢缺口。
### 預期成果
review.json、REVIEW.md、proposed-sources.json、summary.json；分級數量、歧義、疑似重複、可補欄位與寫入差異。
### 實作方向
每列含 rowId、original、recommendedCandidate/null、confidence/null、tier、supportingEvidence、conflicts、alternatives、fieldAvailability、sourceLinks、reviewedAt。來源提案須與現有格式相容，判斷理由另存審閱檔；不擅加 UI 功能。
### 可能影響的系統或資料
隔離預覽及計畫文件；正式資料只讀。
### 階段內任務與並行候選
A3-T1 逐筆判斷（依賴 A2）；A3-T2 編製預覽（依賴 T1）；A3-T3 完整性核對（依賴 T2）。均 parallel_candidate: false，循序執行。
### 必要測試
每目標恰有一份審閱結果；候選引證可定位；來源 ID 與 URL 一致；高信心無未解版本衝突；提議來源在副本可讀；正式檔雜湊不變。
### 完成條件
全部目標有結論或明確未解原因，資料／請求摘要及寫入差異可審閱。交付預覽並停止，更新交接與狀態。
### 人工或外部驗收
類型：blocking（阻擋 A4，不阻擋交付預覽）；使用者確認精確 run 與採用列，記錄 ACC-03。
### 風險與未知事項
信心非機率，自動格式測試不能證明作品身分。

## A4：核准後套用與狀態保留
### 需求對應
REQ-008、REQ-010。
### 目標
僅套用核准列與欄位，有備份及可復原記錄。
### 非目標
不連帶更名、刪除重複、更新評分或更正未核准分類。
### 前置條件與相依階段
A3 PASS，ACC-03 passed，確認精確 run、輸入雜湊與套用列。
### 預期成果
原檔備份、套用清單、前後雜湊、個人狀態核對與背景閱讀器驗收。
### 實作方向
優先原名稱與鍵僅補來源；外部變更重新比對，既有來源不同停止該列。安全寫入、可重跑、失敗可復原，復原亦防外部覆寫。另獲准更名才遷移收藏／隱藏／來訪鍵，保留時間與額外欄位。原報告已有錯誤欄位須另外核准。
### 可能影響的系統或資料
核准的正式來源；報告及個人檔只有更名等特定核准才改。若修改閱讀器，遵守 AGENTS.md 版本、建置及發行要求；資料補齊本身通常不需重建。
### 階段內任務與並行候選
A4-T1 核准範圍核對（依賴 A3）；A4-T2 備份套用（依賴 T1）；A4-T3 狀態畫面驗收（依賴 T2）。均 parallel_candidate: false，循序執行。
### 必要測試
來源衝突拒絕、外部修改阻擋、重跑安全、失敗復原、個人狀態保留；以副本及隱藏視窗驗證顯示，未播放不宣稱影片可播放。
### 完成條件
核准內容補齊，原有來源與個人狀態受保護，有實際驗收與缺口清單。
### 人工或外部驗收
類型：non-blocking；Google Drive 遠端同步和影片實際播放未確認需明列。
### 風險與未知事項
同步衝突、使用中閱讀器記憶體基準、報告已有分類優先顯示。
